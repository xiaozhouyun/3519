# PB31 Key Start Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 PB31 按键中断复用蓝牙启动动作，启动循迹控制。

**Architecture:** PB31 与 PB24 共用现有 `GROUP1_IRQHandler()`；中断中清除 PB31 标志后调用 `Key_Start()`。`Key_Start()` 只转发到 `BT_Start()`，因此启动状态仅由现有蓝牙状态变量维护。

**Tech Stack:** MSPM0 DriverLib、FreeRTOS、Keil ARM C。

## Global Constraints

- 仅处理 PB31 下降沿启动；不增加按键停止、去抖、任务或电机直接控制。
- 不新增第二个 `GROUP1_IRQHandler()`。
- 不自动启动 Keil；由用户提供编译结果。
